# 인스타그램 게시물

| 순서 | 폴더 | 내용 | 이미지 |
|---|---|---|---|
| 1 | [01-service-intro](01-service-intro/) | Trazo 서비스 전반 소개 | 7장 |
| 2 | [02-ai-mcp-update](02-ai-mcp-update/) | AI 연동(ChatGPT·Claude, MCP) 업데이트 | 6장 |

각 폴더의 `caption.md`에 본문, 해시태그, 장별 대체 텍스트, 첫 댓글이 있습니다. 이미지는 인스타그램 권장 세로형 1080×1350(4:5)입니다.

## 올리는 순서

1. 프로필 링크를 확인합니다. 게시물 1은 `https://trazo.runvia.app`, 게시물 2는 `https://trazo.runvia.app/connect`를 가리키면 좋습니다.
2. 새 게시물 → 여러 장 선택에서 `01.png`부터 번호 순서대로 고릅니다. 자르기는 원본(4:5)을 그대로 둡니다.
3. `caption.md`의 본문을 붙여 넣습니다.
4. 고급 설정 → 대체 텍스트 작성에서 장마다 대체 텍스트를 넣습니다.
5. 올린 뒤 첫 댓글을 남깁니다(선택).
6. 게시물 2는 게시물 1을 올리고 며칠 뒤 올리면 피드에서 이어 보기 좋습니다.

## 이미지 고치기

`src/`에 원본 HTML(`01-service-intro.html`, `02-ai-mcp-update.html`), 공통 스타일(`base.css`), 운영 화면 캡처가 있습니다. 문구를 고친 뒤 저장소 루트에서 다시 그립니다.

```
python docs/instagram/src/render.py   # Playwright 필요, 글꼴 때문에 인터넷 연결 필요
```

화면 캡처는 2026-11-10 운영 화면(새 로고 반영 후)입니다. 화면에 공개 코스 이름과 작성자 닉네임('도미네이터')이 보입니다.
