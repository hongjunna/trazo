- 형식: 캐러셀 6장 (`01.png` ~ `06.png`, 1080×1350, 4:5)
- 올리기 전: 프로필 링크를 `https://trazo.runvia.app/connect`(연동센터)로 바꾸거나, 링크를 여러 개 걸 수 있으면 하나 추가

## 대체 텍스트 (장마다)

1. AI 연동 업데이트 표지. "한강에서 뛸 코스 추천해줘"라는 질문에 AI가 [한강 10km] 여의나루-마곡선착장(10.0km, 상승 46m)과 [한강 8km] 동작역-당산역(8.1km, 상승 92m)을 추천하는 대화
2. 동작역 근처 5km 러닝 코스를 비교해 달라는 질문에 AI가 장소를 찾고 코스를 검색해 5km 코스 세 개의 상승 고도를 비교하는 대화 예시
3. AI와 함께 할 수 있는 일 여섯 가지: 오늘의 코스 추천, 장소로 코스 찾기, 훈련 궁합 보기, 라이딩 계획, 공유 링크 분석, 내 코스 정리
4. 연결 방법 네 단계: 주소 trazo.runvia.app/mcp 복사, ChatGPT 플러그인이나 Claude 커넥터에 추가, 구글 로그인 후 허용, 질문하기
5. 안심하고 연결할 수 있는 이유: 읽기 전용, 내가 허용한 경우에만 읽기, 이메일·좋아요·댓글은 넘기지 않음, 언제든 연결 끊기, 무료
6. 내 코스를 AI 러닝 코치에게 맡기라는 문구와 연동센터 주소 trazo.runvia.app/connect
