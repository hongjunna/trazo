# 게시물 1: Trazo 서비스 소개

- 형식: 캐러셀 7장 (`01.png` ~ `07.png`, 1080×1350, 4:5)
- 올리기 전: 프로필 링크를 `https://trazo.runvia.app`으로 설정 (인스타그램 본문 링크는 눌리지 않습니다)

## 본문 (그대로 복사해 붙여 넣기)

```
지도에 점만 찍으면, 나만의 러닝·라이딩 코스가 완성돼요 🗺️

Trazo(트라소)는 스페인어로 '획, 선'이라는 뜻이에요.
지도 위에 선을 긋듯 코스를 만들고, 그 코스로 훈련하고, 함께 달리는 사람들과 나누는 서비스예요.

✔️ 종목에 맞는 길로 자동 연결
자전거는 자전거길로, 러닝은 공원·산책로로 이어 줘요. 큰 차도·계단·오르막 피하기도 골라요.

✔️ 오르막까지 미리 확인
거리·상승 고도·예상 시간, 경사 구간을 색으로 나눈 고도 그래프를 바로 보여줘요.

✔️ 기기로, 친구에게
GPX·FIT·TCX로 내려받아 가민·와후·스트라바에 바로 넣고, 링크 하나로 공유해요.

✔️ 우리 동네 인기 코스
다른 러너·라이더가 공개한 코스를 지도에서 둘러보고 내 코스에 담아요.

✔️ 훈련 도구
러닝 페이스 계산기, 400m 트랙 한 바퀴 기록, 전국 육상 트랙 지도까지.

설치 없이 브라우저에서 무료로 시작하세요.
👉 프로필 링크 또는 trazo.runvia.app

여러분의 단골 코스는 어디인가요? 댓글로 알려 주세요 🏃‍♀️🚴

#트라소 #Trazo #러닝코스 #자전거코스 #러닝 #라이딩 #러닝크루 #자전거라이딩 #GPX #가민 #한강러닝 #마라톤훈련 #코스추천 #러너 #로드바이크
```

## 대체 텍스트 (게시물 → 고급 설정 → 대체 텍스트, 장마다)

1. 지도에 점을 찍으면 나만의 코스가 된다는 문구와, 서울 한양도성을 도는 19.9km 러닝 코스가 그려진 지도
2. 종목에 맞는 길로 이어 준다는 문구와 경로 옵션(공원·산책로 우선, 큰 차도·계단 피하기) 화면, 코스 지도
3. 오르막을 미리 알고 출발하라는 문구와 거리 19.94km·상승 고도 905m·예상 2시간 요약, 경사별 색으로 칠한 고도 그래프
4. GPX·FIT·TCX·KML·GeoJSON으로 내보내고 링크로 공유한다는 문구와 125km 자전거 코스 공유 페이지
5. 우리 동네 인기 코스를 한눈에 본다는 문구와 휴대폰 커뮤니티 코스 목록, 서울 공개 코스 지도
6. 러닝 페이스 계산기·400m 트랙 기록·육상 트랙 지도 소개와 휴대폰 페이스 계산기 화면
7. 지금 무료로 시작하라는 문구와 Trazo 로고, 주소 trazo.runvia.app
