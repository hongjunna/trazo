== 개요 ==
'''RailNow'''(레일나우)는 [[수도권 전철]] 열차의 현재 위치와 지연 정보를 열차번호로 조회하는 웹사이트이다. 개발자용 [[API]]도 제공한다.[* [[https://railnow.runvia.app|RailNow 홈페이지]]]

== 상세 ==
노선을 고르고 [[열차번호]]를 입력하면 그 열차의 현재 역(또는 이동 중인 구간), 다음 역, 행선지, 방향, 열차 종류, 예정 시각, 지연 시간을 보여 준다. 노선별로 운행 중인 열차 목록을 보거나 역별로 지나는 열차를 볼 수도 있다.

위치 정보는 [[서울특별시]]가 공개하는 실시간 지하철 도착정보와 운영기관의 시각표를 함께 써서 계산한다. 실시간 정보가 수 분 간격으로 들어오기 때문에, 그 사이의 위치는 시각표에 지연 시간을 반영해 추정한다.[* [[https://railnow.runvia.app|RailNow 홈페이지]]]

조회 결과에는 정보의 근거가 함께 표시된다.

=== 명칭 ===
'Rail'(철도)과 'Now'(지금)를 합친 이름이다. 처음에는 '실시간 열차 정보 조회 서비스'라는 이름을 썼다. 2026년 10월에 지금의 이름으로 바꾸면서 주소도 {{{railnow.runvia.app}}}으로 옮겼다.

== 기능 ==
=== 열차 조회 ===
열차번호(예: {{{K802}}}, {{{S904}}}, {{{2202}}})와 노선으로 열차를 조회한다. 결과 화면은 15초마다 자동으로 다시 조회된다. 다만 원본 실시간 정보는 수 분 간격으로 갱신된다.

=== 노선별·역별 조회 ===
노선별로 운행 중인 열차 목록을, 역별로 그 역을 지나는 열차를 보여 준다.

=== 열차 시간표 ===
열차번호별로 정차역의 도착·출발 시각을 보여 주는 페이지가 있다. 평일과 휴일 시각표를 따로 보여 주며, [[공휴일]]에는 휴일 시각표가 적용된다.

=== 데이터 현황 ===
노선별로 등록 역 수, 실시간 운행 열차 수, 유효 시각표 수, 역간 거리, 표준 운행시간을 얼마나 확보했는지 공개한다.

=== API ===
개발자 센터에서 [[구글]] 계정으로 로그인하면 API 키를 발급받을 수 있다. API 문서는 한국어와 영어로 제공되며, API 마켓플레이스인 RapidAPI에도 등록되어 있다.[* [[https://rapidapi.com/hongjunna/api/railnow|RapidAPI - RailNow]]]

== 지원 노선 ==
2026년 10월 기준으로 아래 노선을 지원한다. 노선마다 확보한 데이터의 범위는 다르다.[* [[https://railnow.runvia.app/?tab=data|RailNow 데이터 현황]]]
 * [[수도권 전철 1호선|1호선]] ~ [[수도권 전철 9호선|9호선]]
 * [[수도권 전철 경의·중앙선|경의·중앙선]], [[공항철도]], [[수도권 전철 경춘선|경춘선]], [[수도권 전철 수인·분당선|수인·분당선]], [[신분당선]], [[우이신설선]], [[GTX-A]], [[서해선]], [[신림선]]

== 한계 ==
 * 실시간 정보가 들어오는 사이의 위치는 추정값이라서 실제 위치와 다를 수 있다.
 * {{{ESTIMATED}}} 상태에서 지연이 0분으로 표시되어도 실제로 정시 운행 중이라는 뜻은 아니다. 시각표로 계산한 값일 뿐이다.
 * 수도권 밖의 도시철도와 [[KTX]] 같은 간선 열차는 지원하지 않는다.
 * 앱 화면은 한국어만 지원한다. 영어로는 이용 안내 페이지와 API 문서만 제공한다.
